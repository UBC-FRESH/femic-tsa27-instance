# TSR metadata

Tracked here:

- `tsa_documents_with_2022.json` — document metadata and public URLs for the 19-document TSA 27 corpus (18 FTP documents + the September 2022 data package).
- `tsa27_thlb_netdown_table3.csv` — curated TSR4 2010 Table 3 netdown sequence.
- `tsa27_thlb_netdown_table14_2022.csv` — curated 2022 Table 14 land-base classification.
- `tsa27_tsr_cycle_timeline.csv` — cycle, model, caribou treatment, and key numbers.
- `tsa27_caribou_evidence.csv` — short evidence excerpts with document and page references.

Not tracked (generated by the fetch/extract commands):

- `tsa_candidate_facts*.json`
- `tsa_pdf_cache_manifest.json`
- `*.sqlite`

Run `python scripts/fetch_tsr_corpus.py` to materialize the PDFs, then use the FEMIC `tsr extract` command in the README to regenerate the facts.

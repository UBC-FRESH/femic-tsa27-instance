# WS4 target files

Hand-maintained targets:

- `evenflow_caribou.yaml` — S7 even-flow, UWR-restricted dataset.
- `evenflow_no_caribou.yaml` — S8 even-flow, full dataset.

Generated targets:

- `s3_seral_40_10.yaml` — 5,400 period targets (270 accounts, 135 LU/BEC values)
  for the TSR seral rule on `build/compiled_zone_uwr`.

## s3_seral_40_10.yaml

Generated by:

```bash
python scripts/build_seral_targets.py
python scripts/build_seral_targets.py --check
```

The file records the dataset manifest SHA-256, the fractions, and the period structure
in its header. The bounds are absolute hectares because the LU/BEC totals are constant
through the simulation:

- mature + old (≥140 years) ≥ 40% of the LU/BEC area;
- old (≥250 years) ≥ 10% of the LU/BEC area.

The caribou line is not in the instance. The file applies the below-the-line targets
everywhere and says so in the header. Do not read it as a legal determination.

`build/compiled_zone_uwr` is the UWR no-harvest variant: every `uwr` track keeps its
area but has no treatment rows, so the optimizer cannot harvest it. A full 8,107-row
schedule on that dataset reproduces the filtered S3 harvest (13,674,669.395 m³).

FEMIC TSA 27 Revelstoke Instance
================================

Public FEMIC deployment instance and WS4 model case for the Revelstoke TSA (TSA 27), with a
reproducible TSR evidence base and a caribou-policy modelling pipeline.

This site is the RTFM surface for the project. Agents read the relevant page before they act,
and cite it in their reports. Start with the repository's ``AGENTS.md`` and ``ROADMAP.md``.

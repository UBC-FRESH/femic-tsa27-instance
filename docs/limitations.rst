Limitations
===========

- The 2022 TSR5 package is a pre-analysis data package. It does not publish the base case or
  the core/matrix sensitivity results, so the WS4 implementation is a documented best guess.
- The 1994 TSR documents are scanned images with no text layer; the 1999–2022 cycles carry the
  machine-readable caribou narrative.
- The TSR4 2010 and 2022 land-base tables use different bases (CFLB versus AFLB) and different
  UWR boundaries. Their caribou areas are not directly comparable.
- The 2010 TSR4 sensitivities are the quantitative benchmark. The 2022 policy has no published
  quantitative result yet.
- Provincial data vintages, caribou layer versions, and BEC versions can change the answer.
  Every run therefore records the input manifest and version.
- The repository does not redistribute raw data or TSR PDFs; users must fetch them from the
  public sources.
